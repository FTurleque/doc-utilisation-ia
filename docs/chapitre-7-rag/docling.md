# Docling — rôle dans le pipeline RAG

Docling prépare les documents pour le RAG : extraction, mise en page, OCR et préparation des chunks. Conservez la provenance et les droits d’accès pendant ces transformations ; un texte bien extrait reste une donnée non fiable pour le modèle.
