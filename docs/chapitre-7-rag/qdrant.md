# Qdrant — rôle dans le retrieval RAG

Qdrant stocke les vecteurs et retrouve les passages pertinents avec leurs métadonnées. Dans le RAG, appliquez les contraintes d’accès avant de transmettre les résultats au modèle ; la pertinence d’un passage ne constitue pas une autorisation.
