# Vidéos, podcasts & conférences

<span class="badge-beginner">Débutant</span>

Les formats audio/vidéo sont utiles pour comprendre des démonstrations, suivre des retours d'expérience et découvrir de nouveaux sujets. Ils restent cependant **des sources secondaires** : pour une information produit, un prix, une fonctionnalité ou une faille, revenez ensuite à la source officielle.

## Ce qu'il faut éviter dans la documentation

Ne recopiez pas durablement :

- une fréquence de publication supposée ;
- un nombre d'abonnés/membres ;
- une liste « meilleures chaînes » présentée comme objective ;
- une date annuelle de conférence si l'organisateur ne l'a pas encore publiée ;
- une affirmation technique tirée uniquement d'une vidéo.

Ces informations vieillissent rapidement et apportent peu de valeur au dépôt.

---

## Utiliser une vidéo comme signal

Workflow recommandé :

```text
vidéo / podcast / conférence
→ identifier l'affirmation utile
→ retrouver la documentation, le changelog, le dépôt ou le papier primaire
→ vérifier la date et le statut
→ seulement ensuite mettre à jour la documentation
```

## Contenu francophone

Les sources francophones peuvent être utiles pour la vulgarisation ou le partage en équipe. Elles ne doivent pas être privilégiées au détriment d'une documentation officielle anglophone lorsqu'il faut vérifier un comportement produit précis.
