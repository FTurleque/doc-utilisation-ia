# Choisir un framework de deep learning

Le choix d’un framework dépend du modèle, des opérations nécessaires, du matériel et de la cible de déploiement. Comparez les candidats sur une baseline commune et vérifiez la reproductibilité avant d’élargir l’expérimentation.

## Repères dans ce chapitre

- PyTorch : considérer les besoins de contrôle du code et le chemin d’export.
- TensorFlow : vérifier les intégrations d’entraînement et de serving du projet.
- Keras : examiner la compatibilité des opérations avec le backend retenu.
- JAX : valider les opérations, les transformations et la cible matérielle.
